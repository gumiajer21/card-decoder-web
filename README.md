# 卡片解码者网页版

《游戏王：大师决斗》“卡片解码者”活动的非官方辅助工具。网页的求解、测试、小游戏和规模测试均在浏览器本地运行，不需要安装，也不需要后端服务。

**在线使用：<https://gumiajer21.github.io/card-decoder-web/>**

## 快速使用

1. 按游戏画面录入初始揭示的字段。
2. 点击“计算最佳挑战”，按照推荐选择提示或挑战卡。
3. 挑战后勾选游戏中点亮的字段；若边框点亮，再选择游戏揭示的完整目标边框。
4. 完全猜中后进入下一题。浏览器会自动保存当前活动进度。

如需隔日或跨设备继续，可通过页面顶部的“导入／导出活动”保存 JSON 文件，也可以使用逐项补录功能恢复行动记录。

## 功能

- 六项线索录入、挑战反馈和求解建议
- 按官方规则处理灵摆边框：目标为灵摆卡时，命中任一组成边框即相符，并记录游戏揭示的完整边框
- 六项点亮与整卡通关分开判定：灵摆组成边框可点亮并计入相符项，但完整边框不同不会误判通关
- 边框点亮后不再默认选择挑战卡边框，必须按游戏画面显式选择完整目标边框，避免组合边框被误录
- 活动记录导入／导出，以及逐步勾选式补录
- 完整数据库多条件筛选、排序和图格／列表浏览
- 测试模式、小游戏模式和 1／2／4／8 路并行规模测试
- 无外部卡图依赖的仿卡面信息卡，可点击放大

## 数据与隐私

- 当前卡库按 Master Duel 游戏内名单与卡片密码映射交叉校准，但科乐美未公开本活动的完整抽题名单，候选范围仍可能存在极小误差。
- 所有求解、模拟和活动记录都在访问者的浏览器中处理；活动记录不会上传到项目服务器。
- 网页使用 Cloudflare Web Analytics 查看匿名访问量和性能指标，不用于识别具体用户。
- 项目不包含官方卡图或壁纸；候选卡以网页即时生成的仿卡面信息卡展示。

## 发布

仓库中的 `docs` 是完整部署目录。GitHub Pages 可直接从 `main` 分支的 `docs` 目录发布，不需要 Actions 工作流。

首次部署前，在 GitHub 仓库中打开：

1. `Settings` → `Pages`
2. 将 `Source` 设为 `Deploy from a branch`
3. Branch 选择 `main`，目录选择 `/docs`
4. 点击 `Save`

之后只需将更新推送到 `main` 分支，原网页链接会自动更新。若仍看到旧版，可等待几分钟后使用 `Ctrl + F5` 强制刷新。
